# ⌨️ Typing Warrior

맥(macOS)과 윈도우(Windows)에서 동작하는 한글/영문 타자연습 프로그램입니다.
연습 화면을 최대한 넓게 쓰고, 통계는 하단 상태바에 작게 표시해 연습에 집중할 수 있게 구성했습니다.

## 실행하기

```bash
npm install      # 처음 한 번
npm start        # 데스크톱 앱 실행 (Electron)
npm run serve    # 브라우저 미리보기: http://127.0.0.1:5173
npm test         # 단위 테스트 (한글 조합기, 키보드 배열, 통계)
```

설치 파일 만들기 (`dist/` 폴더에 생성):

```bash
npm run dist:mac   # macOS .dmg (맥에서 실행)
npm run dist:win   # Windows 설치본 + 포터블 .exe
```

## 기능

| 메뉴 | 내용 |
|------|------|
| 자리 연습 | 한글 7단계(기본자리 → 윗줄 → 아랫줄 → 쌍자음 → 쌍모음 → 복모음 → 숫자·기호), 영문 6단계, 🔀 혼합 모드 |
| 단어 | 일상·자연·음식·쌍자음/겹받침·신앙 / English basic·everyday·advanced·faith |
| 문장 | 📅 오늘의 말씀(날짜별 암송 구절), 명언 100개, 성경 암송 365구절(개역한글), 같은 구절의 영어 성경 365구절(KJV), 영어 문장 30개 |
| 📜 긴 글 | 한 줄(절)씩 이어서 타이핑, 작품마다 진행 위치 저장. 한글: 성경 전권(개역한글, 책→장), 김소월 『진달래꽃』, 윤동주 『하늘과 바람과 별과 시』, 한용운 『님의 침묵』, 한국 근대시 모음 / 영문: 성경 전권(KJV), 셰익스피어 소네트 154편, 에밀리 디킨슨 시집 |
| 📂 내 글·내 성경 | 긴 글에서 텍스트 파일(.txt)을 불러와 연습. 성경 전권 파일(CSV, XML: Zefania·OSIS·OpenSong·Beblia, TXT)을 올리면 개역한글·KJV 대신 그 역본으로 성경 전권·암송 365구절을 연습. 형식은 화면의 ❔ 파일 형식과 `docs/samples/` 참고 |
| ℹ️ 소개 | 프로그램 소개와 모든 연습 글의 출처·저작권 근거 |
| 🧱 단어블록게임 | 떨어지는 단어 입력. ♾️ 연속 모드(12단어마다 레벨 상승) / 🎯 단계 모드(LEVEL 1~20, 단어 20개를 막으면 다음 레벨 열림). 레벨 10 = 분당 200타 기준. 💣 금색 단어 = 화면 정리, ❄️ 파란 단어 = 5초 감속 |
| 🎖️ 전선 작전 | 1인칭 전장 타자 게임. 탄약·재장전("장전"), 7연속 명중 시 공습("공습"), 5웨이브마다 지휘관(긴 문장) |
| 단축키 | macOS / Windows 기본 단축키를 실제로 눌러 연습. 1단계 기본 → 2단계 문서·브라우저 → 3단계 텍스트 이동, 🔀 전체 + 📋 단축키 표. 화면 키보드에 Ctrl·Alt·⌘·Esc·F1~F12·방향키까지 표시되고, 키보드를 보이면 정답 키가 켜지고 감추면(F2) 외워서 누르기 |
| 📊 기록 | 연속 연습일, 오늘/총 연습 시간, 모드별 최고 기록, 최근 기록 |

**게임 옵션 (입력칸 옆)**: 효과음 세트 🔈 잔잔 / 🔉 아케이드 / 🔊 도파민(연속 명중할수록 음이 올라감) · 글자 크기 100~200%
전선 작전에는 🎖️ 전장 세트가 더 있습니다(기본값): 실감 나는 총성·탄피·재장전 소리에 포격, 원거리 교전, 총알 스치는 소리, 무전, 체력이 낮을 때 빨라지는 심장박동이 배경으로 깔립니다. 효과음 세트는 게임마다 따로 저장됩니다.

**화면 도구 (오른쪽 위)**: 🌐 화면 표시 언어(한국어/English) · 한/EN 연습 언어 전환 · ⌨ 키보드 표시 · 🖐 손가락 색상 · 🔊 효과음 · 🌙/☀️ 테마 · ⛶ 전체화면

**단축키**: `F2` 키보드 표시/숨김 · `F3` 손가락 색상 · `Shift+Space` 또는 `한/영` 키로 언어 전환 · `F11` 전체화면 · `Esc` 게임 일시정지

단계를 마치면 결과(타수·정확도·시간)와 함께 응원 메시지가 나오고, 최고 기록을 넘으면 축하 효과가 표시됩니다.

## 설계 메모

- **화면 표시 언어와 연습 언어 분리**: 메뉴·설명·결과 문구는 🌐 버튼으로 고른 화면 언어(`src/renderer/i18n/ko.js`, `en.js`)로, 연습 내용은 한/EN 버튼으로 고른 연습 언어로 나옵니다. 그래서 영어 화면으로 한글 타자를 연습할 수 있습니다. 처음 실행하면 운영체제 언어를 따릅니다.

- **운영체제 입력기와 무관하게 동작**: 키의 물리적 위치(`KeyboardEvent.code`)를 읽어 앱이 직접 두벌식 한글을 조합합니다(`src/renderer/core/hangul.js`). 그래서 macOS/Windows에서 한/영 입력 상태가 달라도 연습이 똑같이 동작합니다.
- **타수 계산**: 한 글자를 치는 데 필요한 키 입력 수(예: `과` = ㄱ+ㅗ+ㅏ = 3타) 기준의 분당 타수입니다.
- **조합 중 표시**: 받침이 다음 글자로 넘어가는 경우(`갑` → `가바`)에도 틀린 것으로 표시하지 않도록 키 입력 단위로 비교합니다.
- 기록과 설정은 앱 내부 저장소(localStorage)에 저장됩니다.

## 데이터

- `src/renderer/data/bible.js`는 `tools/build-bible.py`로 로컬 성경 DB에서 생성했습니다. 개역한글은 저작권이 만료된 번역본이라 기본값으로 사용합니다.
  다른 번역본으로 바꾸려면: `python3 tools/build-bible.py 개역개정` (개인 연습용으로만 사용하세요).
- 영어 성경 구절과 시편도 같은 스크립트로 만듭니다: `python3 tools/build-bible.py english`, 성경 전권: `python3 tools/build-bible.py full`, `python3 tools/build-bible.py full KJV`. 암송 365구절 목록은 `tools/memory-verses.txt`에 있습니다. 로컬 DB의 KJV는 CrossWire KJV(eBible.org, 1769년판 기준)로 교체한 본문입니다.
- 시집 데이터는 `tools/build-poetry.py`로 만듭니다: `python3 tools/build-poetry.py fetch <폴더>`로 구텐베르크와 위키문헌에서 원문을 받고, `python3 tools/build-poetry.py build <폴더>`로 `poetry-ko.js`, `poetry-en.js`를 씁니다. 윤동주 초판의 한자는 `tools/hanja-readings.json`의 독음으로 바꿉니다.
- 각 작품의 출처, 판본, 저작권 근거는 앱의 **ℹ️ 소개** 화면(`src/renderer/data/about.js`)에 정리했습니다. 위키문헌의 현대어 표기 본문은 CC BY-SA 4.0으로 다시 배포합니다.
- 단어·명언·단축키는 `src/renderer/data/`의 파일을 고치면 바로 반영됩니다.

## 폴더 구조

```
src/main/        Electron 메인 프로세스 (창, 전체화면, 메뉴)
src/renderer/
  core/          한글 조합, 키보드 배열, 통계, 저장, 효과음, 응원 메시지
  ui/            화면 키보드, 결과 창, 입력 줄 등 공용 UI
  modes/         연습 모드와 게임
  data/          단어, 명언, 성경, 단축키, 자리 연습 단계
  styles/        라이트/다크 테마와 화면 스타일
tests/           node:test 단위 테스트
tools/           성경 데이터 생성, 미리보기 서버
```
