# 개인정보 처리방침 · Privacy Policy

**Typing Warrior** (macOS · Windows) · 시행일 2026-11-01 · 만든 사람: 박기현 (Gihyun Park)

## 한국어

Typing Warrior는 **개인정보를 수집하지 않습니다.**

- **이 컴퓨터에만 저장하는 것**: 사용자 이름, 화면·연습 언어, 연습 기록, 진행 위치, 배지, 불러온 글과 성경 파일. 모두 이 컴퓨터 안(앱 저장 공간)에만 저장되고 만든 사람이나 다른 서버로 보내지 않습니다. 앱을 지우거나 **기록 초기화**를 하면 지워집니다.
- **광고·분석·추적 없음**: 광고, 사용 통계, 오류 보고, 추적 도구를 넣지 않았습니다.
- **인터넷을 쓰는 유일한 기능 — API.Bible에서 받기**: 사용자가 직접 실행할 때만 [API.Bible](https://scripture.api.bible)에 접속해 성경 본문을 받습니다. 이때 사용자가 입력한 API 키가 API.Bible로 전송되고, API.Bible의 저작권 이용 보고(FUMS)가 함께 전송됩니다. 이 정보는 API.Bible의 [개인정보 처리방침](https://www.americanbible.org/about/privacy-policy)을 따릅니다. API 키는 운영체제의 보안 저장소(macOS 키체인 등)에 암호화해 이 컴퓨터에만 보관합니다.
- **링크**: 소개 페이지의 링크(홈페이지, GitHub, 후원)를 누르면 기본 웹 브라우저가 열리며, 그 뒤는 각 사이트의 방침을 따릅니다.
- **어린이**: 연령과 관계없이 개인정보를 수집하지 않습니다.
- **문의**: [GitHub Issues](https://github.com/ccumgol/typing-warrior/issues) · https://jesusiswith.us

방침이 바뀌면 이 문서와 앱의 바뀐 내용(CHANGELOG)에 알립니다.

## English

Typing Warrior **does not collect any personal data.**

- **Stored only on this computer**: user names, display and practice languages, practice records, reading positions, badges, and imported texts and Bible files. Nothing is sent to the developer or any other server. Deleting the app or using **Reset records** removes it.
- **No ads, analytics or tracking.**
- **The only online feature — Get from API.Bible**: only when you start it, the app connects to [API.Bible](https://scripture.api.bible) to download Bible text. Your own API key and API.Bible's usage report (FUMS) are sent to API.Bible, under API.Bible's [privacy policy](https://www.americanbible.org/about/privacy-policy). The key is kept encrypted in the operating system's secure storage (e.g. the macOS Keychain) on this computer only.
- **Links** on the About page open your web browser; those sites have their own policies.
- **Children**: no personal data is collected from anyone, of any age.
- **Contact**: [GitHub Issues](https://github.com/ccumgol/typing-warrior/issues) · https://jesusiswith.us
